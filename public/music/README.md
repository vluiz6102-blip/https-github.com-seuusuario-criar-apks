# Música do Pulso 90

Coloque nesta pasta apenas faixas próprias ou licenciadas para uso no jogo.

Edite playlist.json e adicione objetos com title e src, por exemplo:

```json
{"tracks":[{"title":"Faixa licenciada","src":"/music/tracks/faixa-licenciada.mp3"}]}
```

A trilha original sintetizada pelo jogo continua como fallback quando a playlist estiver vazia ou indisponível. Não adicione músicas comerciais protegidas sem autorização prévia e expressa.
